# 🚀 Quick Start Guide

## Update Your Website in 3 Steps

### 1️⃣ Setup GitHub Token (One-Time, 2 minutes)

1. Go to: https://github.com/settings/tokens/new
2. Name: `La Scuderia CMS`
3. Check: ✅ `repo`
4. Click: **Generate token**
5. Copy the token (starts with `ghp_`)

### 2️⃣ Add Token to CMS (One-Time, 30 seconds)

1. Open: http://localhost:8000/admin/
2. Click: **"🔑 Setup GitHub"**
3. Paste your token
4. Click: **"💾 Save Token"**

### 3️⃣ Publish Changes (Every Time, 10 seconds)

1. Edit content in CMS
2. Click: **"🚀 Publish to GitHub"**
3. Wait 1-2 minutes
4. **Done!** Changes are live!

## 🆘 Need Help?

### Token not working?
- Make sure you selected `repo` scope
- Copy the entire token
- Create a new one if needed

### Publish button missing?
- Click "🔑 Setup GitHub"
- Add your token
- Refresh the page

### Changes not appearing?
- Wait 2-3 minutes
- Hard refresh (Ctrl+Shift+R)
- Check: https://github.com/PaulKremershof/Website-la-scuderia/actions
